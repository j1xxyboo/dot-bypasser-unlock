Extension patcher

Drop in the official extension file and get the patched version back. No commands, no terminal.

1 — choose the file

Drop the extension file here
or click to choose — .zip or .crx
Have an unpacked folder? Right click it → Compress to ZIP first.

2 — install the patched extension

  1. Unzip the downloaded file.
  2. Open chrome://extensions in Chrome.
  3. Turn on Developer mode (top right).
  4. Click Load unpacked and select the folder you just unzipped.
  5. Pin the extension and click its icon — the premium features are unlocked.

Only the official release is accepted — the service checks the file against the vendor's own signed manifest before touching it. Nothing is stored; the file is patched in a temporary folder and deleted right afterwards.
